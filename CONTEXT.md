# arthurfaria.com

A personal portfolio presented as an Instagram Reels-style feed — the "brainrot portfolio." This glossary covers vocabulary specific to that concept, not general Next.js/React terms.

## Language

**Reel**:
The atomic, full-bleed swipeable unit of the feed. Always presented in Instagram's native vertical proportions — edge-to-edge on mobile, a narrow centered ~9:16 card on desktop (never a wide arbitrary rectangle). Content inside a Reel must fit without internal scrolling, matching how a real Reels app never lets you scroll inside a single video.
_Avoid_: Section, slide, page

**Brainrot Video**:
The looping decorative background footage (GTA, Subway Surfers, satisfying clips, etc.) playing behind serious portfolio content on the Experience reels. The joke is the deliberate mismatch between silly footage and professional content — this is the portfolio's core bit and doesn't need reinforcing with new jokes.
_Avoid_: Background video

**Projects Pagination**:
Projects are split across several sequential Reels (currently "Projects", "More Projects", "More Projects again") instead of one Reel holding every project, each showing a handful of full detail cards (name, description, language) so the set fits without internal scrolling. Each reel's header (eyebrow + bold title, centered) matches the Contact/Experience reel header pattern.
_Avoid_: Projects Grid, project list, project cards
